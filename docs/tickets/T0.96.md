## Objective

A developer at any checkout can list the board identity's keys with one command, `pnpm
board:ids`, without opening the file. Smoke D: a scheduled run adds a package script and its test
end to end — claim, branch, red-first tests, review, report, pull request — on a change small
enough that the protocol is the whole of the work.

## Build

`scripts/board-ids.mjs`: a pure `boardIds(text)` that returns the top-level keys of a JSON
document in file order, and a CLI that reads `.claude/board.json` from the repository root and
prints one key per line. A `board:ids` entry in `package.json` that runs it.
`scripts/board-ids.test.mjs` covering the three criteria.

## Rules

The shape of `scripts/run/*`: export the function, run the CLI only under `isMain` so a test's
import does not execute it. Read the file relative to the repository root, not the working
directory, so the command works from a worktree or a subdirectory. Keys only, never values: the
file holds ids and the prefix, and this command is a listing of what is configured, not of what
it is set to. No new dependency.

## Criteria

AC1 `pnpm board:ids` from the repository root prints every top-level key of `.claude/board.json`,
one per line, in file order, and exits 0.

AC2 The output contains no value from the file — no id and not the prefix — keys only.

AC3 `boardIds(text)` is a pure function of the JSON text: it returns the keys in order, and a
document that is not a JSON object is refused with an error naming `board.json` rather than
printing nothing.

## Tests

TC1 → AC1 `scripts/board-ids.test.mjs` "prints the keys of the committed board.json, one per
line, in order": the CLI's stdout over the real file equals the file's keys joined by newlines,
exit 0, and `package.json` has the `board:ids` script pointing at it.

TC2 → AC2 `scripts/board-ids.test.mjs` "prints no value": none of the committed file's values
appears in the output.

TC3 → AC3 `scripts/board-ids.test.mjs` "refuses a document that is not an object, naming the
file": `boardIds("[]")` and `boardIds("nope")` throw with `board.json` in the message.
