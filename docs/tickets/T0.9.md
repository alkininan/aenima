## Objective

Close the debts the fixture runs left so an unattended run is safe: the guard matches commands,
not text; a pipeline run cannot merge; a run that dies partway recovers on its own; the one flaky
test is fixed; Decision fires only when a wrong guess is expensive to undo; comments read like a
person wrote them; the reviewer stops racing the gate.

## Build

Read first, fully: docs/guidelines.md, docs/reports/T0.8.md (its open questions are this ticket's
list), docs/reports/T0.98.md, docs/reports/T0.99.md, .claude/skills/ticket/*,

1. **Guard tokenizer.** The guard currently matches raw text and has refused a heredoc that
   mentioned db:migrate three times now. Replace with a small command parser: split the Bash
   string into commands on `;` `&&` `||` `|` newline and `\`-continuation, honour single and
   double quotes, and treat heredoc bodies as data. Rules match on argv — the executable (after
   env-var prefixes and `git -C <path>`) and its arguments — never on prose. Existing rules carry
   over unchanged in effect; add: `gh pr merge` refused while .claude/.run-active exists. Tests,
   each reddened by a named mutation: heredoc mentioning db:migrate → allowed · `echo "pnpm
   db:push"` → allowed · `pnpm db:push` → refused · `FOO=1 git -C x push -f` → refused · `gh pr
   merge 3` refused with marker, allowed without.
2. **Run marker.** scripts/run/claim writes .claude/.run-active (task id, page id, branch, started
   ISO, session id) at claim; every exit path — Review, Decision, error — removes it; a trap
   covers the error path. Gitignored. The skill never reads or reasons about it; only scripts do.
3. **Stale-run recovery, preflight 0c replaces "stop and report".** A task at In progress whose
   marker is absent in this checkout, or whose marker is older than three hours, is stale.
   Recovery is automatic: rename its branch t<id>-stale-<HHMM> for salvage, post one plain
   comment ("This run stopped partway on <date>; I've kept the branch as <name> and started
   again from main"), re-claim the same task from origin/main, continue. No human needed — the
   branch is preserved, so a wrong guess costs nothing.
4. **Guidelines §4 rewritten, two changes.** (a) Stop only when a wrong guess is expensive to
   undo. A choice is expensive if it touches the database schema or stored data, a public surface
   (a route, user-facing copy, an API shape), or would need the spec to record it. Everything
   else: take the stated default, say so in one comment, keep building. Smoke B's release-message
   wording would not have stopped under this rule. (b) Comments in plain sentences, no labels.
   Two or three sentences: what it hit, why it could not pick alone, what it chose or would
   choose. Keep the ⟡ prefix. Where the gap lives is said in words ("this isn't written down
   anywhere", "§7.2 says both things"), not as a field. Rewrite every comment the skill posts to
   this shape: decision, clarifying, migration, stale-run, chose-the-default.
5. **Reviewer scope.** The reviewer runs only the tests the ticket's Tests section names plus any
   test file the diff touches; the Stop gate owns the full suite. Update reviewer.md and §5. This
   ends the two-suites-on-one-machine collision.
6. **SignInForm.dom.test.tsx.** The debounce assertions race real timers and fail on a slow
   machine for any reason — under load, and once alone on a clean tree. Move them to fake timers
   or await the debounced state; do not raise a timeout. Observe 20 consecutive green runs of the
   file alone and 5 full-suite runs. Close the Backlog row "Raise SignInForm dom test timeout":
   rename it to what was done, Commit, Status Done.
7. **Skill step 8 vs §5.** §5 is the source; commit belongs to 9 Close. Fix the skill and
   scripts/run/README.md. Close that Backlog row the same way.
8. **Red-first record.** T0.8's own report had none. The skill's step 4 records, per test, the
   mutation or missing file that made it red and the count that went green; step 8 refuses to
   write a report without it.
9. **docs/guidelines.md → v1.4:** §4 as above; §5 for the marker, stale recovery, reviewer scope,
   the red-first record; §6 unchanged. Header line.
