## What the transcript and the board said that changed the pack's shape

Read on 2026-09-14 from the files and the API, not from memory.

1. **A transcript writes one API message as one line per content block, and every line repeats
   the message's usage.** This session's own transcript had 73 assistant lines for 16 message ids
   (up to 11 lines for one), identical usage on each; T0.10's idle run 1 had 35 lines for 13. Summing
   lines gives exactly the numbers in T0.10's table (946 + 20,281); summing once per `message.id`
   gives 358 + 7,076. So the table over-counted by the blocks-per-message ratio, and the rows this
   ticket writes count once per message. AC1 says "the values from the report's table"; the rows
   carry the correct values instead, and the default comment on the task says so.
2. **`NOTION_TOKEN` is rejected.** Preflight's `threads.mjs` got `401` from
   `POST /data_sources/…/query`; the value in `.env.local` (primary and worktree alike) is 17
   characters with the `ntn_` prefix, where a real internal-integration token is about 50. Nothing
   read the board's comments this run; `runs.mjs` posting a row got the same `401`; `mirror.mjs`
   could not read a header. The setup comment at close says where the token goes and which
   capabilities the integration now needs (read, insert, comment).
3. **Notion rewrites what it is handed, in two ways that matter to the header swap.** Bold around
   inline code comes back split — `**Mirror of ****\`CLAUDE.md\`**** — …**` — and a bare `x.md`
   comes back auto-linked — `**Mirror of **[**AGENTS.md**](http://AGENTS.md)** — …**`. The
   connector's `update_content` needs `old_str` to match the page's own rendering, so the first
   two header shapes failed the swap (`No matches found`). The shape shipped keeps the path in
   inline code outside the bold and words alone inside it; probed on a private scratch page (whole
   callout as `old_str`, matched) and then used on the three live pages.
4. **The SessionEnd payload carries `session_id`, `cwd`, `transcript_path`, `hook_event_name`
   and `reason`**, observed live (below): the session id equals `CLAUDE_CODE_SESSION_ID` as the
   Bash tool saw it, which is what T0.9's open question 5 asked.
5. **`--allowedTools` is variadic on `claude -p`** and swallows a prompt placed after it; the
   prompt goes first. `timeout` is not on macOS. Neither is in the code; both cost a retry.
