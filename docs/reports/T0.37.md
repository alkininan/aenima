# T0.37 — Morph menus and selects

Menus, selects, toasts and tooltips follow design-spec v2.22's §6 morph: a panel is a popover in
the top layer, placed by one rule both placement paths share, opened through one same-document
view transition whose names live only for its duration, and closed at once on every path. Toasts
are one at a time, bottom-centre, with `Cmd/Ctrl+Z` on a showing undo and a host that moves into an
open modal; the tooltip has its hover bridge and flip; only §5's three surfaces carry a blur; and
the kitchen-sink route takes `data-force-fallback` through `?fallback=1`.

The ticket was claimed twice. The first claim built most of it and stopped at Decision on §6's
three sentences — anchor positioning, a `visibility: hidden` trigger, and never
`position-visibility` cannot all hold in Chromium. The answer was *default*: the trigger hides by
`opacity: 0` and `pointer-events: none`. This claim built that answer, took main in, and carried the
ticket through three review passes.

Pass 2 found no Must. Its first Should, a real defect this diff opened — an undo pressable twice

test passed on the code it was written against and was removed rather than kept as a test of
nothing.

Pass 3 found no Must and twelve Shoulds, recorded in `docs/reviews/T0.37.md` and not built,

## Open questions

1. **Design-spec §6 still says the trigger is `visibility: hidden`.** The code and its tests pin
   `opacity: 0` and `pointer-events: none`. Guidelines §4 says a Decision whose gap is in a spec is
   patched as the run's first act after claim; here the patch had already been cut as its own
   task, *Design-spec §6: the morph's trigger hides by opacity* (Ready, blocked on this one), so
   this claim left it there rather than build a second copy. Owner: that task.
2. **C-10's floor for controls smaller than it** — the transparent `::before` extension on sm and
   md buttons, chips, tabs, the toggle, checkbox and radio, the drag handle, the header chevron and
   the copy button. None is a surface this ticket touches. Owner: *Extend small controls to the hit
   floor* (Backlog).
3. **A menu's typed-letter jump** (§8.18, §11, C-46, which the ticket does not cite). Owner: *Jump
   a menu cursor by typed letter* (Backlog).
4. **Pass 3's standing Shoulds** — the positioner's clamp at the viewport edge that the anchored
   path lacks, the `focusRef` sync, a toast remounting when a modal opens beneath it, a skippable
   mid-morph sample, the tooltip's crossing inside a modal and its flip to top untested, two unused
   resets and a duplicated helper, C-14's rect comparison covering the menu alone, C-48's sheet
   exit unread, and a closed `Panel` mounting mid-morph skipping another's. Owner: *Close T0.37s
   standing review Shoulds* (Backlog).
5. **What waits on surfaces that do not exist yet.** C-11's pipeline-strip clause, and §8.20's
   "8 above a bottom-pinned bar when one shows" — there is no strip and no bottom-pinned bar in the
   product. Owner: the tickets that build them.
6. **The whole Chromium e2e project times out at the default worker count** against one dev server:
   different tests each run, all at 30s, while two workers pass. Not this ticket's, and worth a
   look if `pnpm e2e` is ever run unattended.
