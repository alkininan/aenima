# T0.23 — Partial reviews and mirror verification

Branch `t0-23` off `origin/main` at `11a0be4`. Three things a run met half-done now end in the
truth. A reviewer pass that stops at its turn limit is read as that, resumed once in its own
session and marked resumed in the report, and a second stop is a stop. A mirror page is read back
after every chunk, so a write cut off partway is rewritten once from its sentinel rather than
headed as whole. And when the connector's query has spent the workspace's usage limit, the
preflight asks the same questions over the integration token with `rows.mjs` and says so.
Guidelines v1.15 carries all three, with §3's In progress → Decision row naming the review that
could not run.

## Defaults taken under §4

Each is a developer surface — a script, its message, a document the run owns — and cheap to
change; all go in the claim's one `default` comment.

1. **A page that reads short is rewritten from its sentinel, the whole page, once.** The ticket
   says "rewrite that chunk once"; a connector write can only append, or replace text it matches
   exactly, and what a cut-off write left behind is not text the run can match reliably — the
   hand patch on 2026-09-16 matched the fragment's last words and was itself cut off. So the page
   goes back to the sentinel alone and the chunks are written again, each read back; a second
   short read leaves the sentinel standing, and the next preflight refreshes that page first.
2. **"Compare its length" is letters and digits, within 64, and the ending.** Notion renders a
   handful of characters its own way (measured above), so an exact length would rewrite whole
   pages for nothing; a truncation of any size at the end is caught by the last 48 letters sent,
   and a loss of more than 64 anywhere by the length.
3. **The read-back reads the whole page every time**, not only the blocks a chunk added — simpler
   than carrying a cursor between commands, at up to 39 s a read on build-log.
4. **AC4 needed no code.** `decide` has skipped a page whose heading carries its file's last
   commit on `origin/main` since T0.12 — a skip that holds while main moves, where main's own head
   would rewrite every page at every merge. TC4 holds it for all eight pages at once.
5. **The turn-limit note is read from Claude Code's own words**, as the reviewer's transcripts hold
   it (T0.12, T0.17, T1.4, T2.9, T2.10): "NOTE: this agent stopped at its 30-turn limit before finishing",
   then no report or partial output. The resume is one fixed line with no briefing.
6. **The reviewer table gains `resumed`, `yes` or `no`, and its verdict must be `PASS` or
   `FINDINGS`**, so a pass that reached no verdict cannot stand as a row. Reports before this one
   lack the column and would be refused now; nothing re-reads them.
7. **The token is the fallback, not the first reader.** The ticket says "when it is exhausted", so
   the connector's query stays first and `rows.mjs` answers only once the connector says the
   workspace has reached the usage limit. It covers the four step 0 questions the connector asks —
   In progress, Review, the newest release, the task a revert names — and `task()` reads `Commit`
   so a Review row read over the token carries what `merge-detect.mjs` needs.

## Open questions

1. **The token could be the preflight's only reader of the board**, not only its fallback: every
   step 0 question `rows.mjs` answers is one the connector's query spends quota on, and the token
   has no such limit. This ticket kept the connector first because it asked for a fallback. Owner:
   Phase 0, E0.2 Pipeline.
2. **The read-back's cost on a long page.** build-log is read whole after each of its five chunks,
   about two minutes of preflight when it is refreshed; reading only the blocks after the last one
   verified would cut that, at the price of a cursor carried between commands. Owner: Phase 0,
   E0.2 Pipeline.
3. **A page Notion renders more than 64 letters its own way** would read wrong on every
   refresh, be rewritten once and left under its sentinel at every preflight after (review pass 1,
   Should 3). Nothing mirrored today comes near — the eight pages were 7 apart at most — but a
   markdown link whose title `written` does not strip, or an HTML comment Notion keeps in one
   place and drops in another, could. The read-back's own `sent` and `found` say which page and by
   how much, and the report line carries it. Owner: Phase 0, E0.2 Pipeline.
4. **T0.22's open question 3 stands** — a model the API cannot find — untouched by this ticket.
   Owner: Phase 0, E0.2 Pipeline.
