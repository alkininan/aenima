## Out of scope

- **`branch.mjs` cannot carry the planner's ticket file across a reused branch.** On a second
  claim — an addendum round, a Decision answered, a migration applied — the planner writes
  `docs/tickets/<id>.md` in a worktree standing at `origin/main`, where that path is untracked,
  and step 3 then runs `git checkout -B t<id> origin/t<id>` against a branch that tracks the same
  path. Git refuses the checkout whenever an untracked file stands where a tracked one would
  land, identical content included — tested both ways in a scratch repository on this machine:
  "untracked working tree files would be overwritten by checkout" — so `createBranch` answers
  `ok: false` and the builder's file turns a mechanical collision into a `refused` stop, while
  the planner's copy is the round's reading and the branch's is the previous claim's. Whether the
  earlier addendum rounds (T2.9, T3.2) met it is not on record; a phase does what its file says.
  `createBranch` should, when `reused` is true, move the ticket file aside, check out, and put it
  back, with `branch.test.mjs` covering it; until then every second claim in a fresh worktree
  meets this. T0.45's second claim is the first under the phase model to reach it: the first
  claim left `docs/tickets/T0.45.md` on `origin/t0-45` at `87da278`, and this worktree holds the
  round's copy untracked.
