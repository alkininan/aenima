# T0.16 — report

Self-merge: a finished ticket merges itself. The board's Status is read as the select it is, so the
guard and the preflight see a task at Review again; the reviewer's verdict is a file the guard
reads; `gh pr merge` has a second door — the PASS on file, a diff touching no gated path, the
pull request's head equal to the checkout's HEAD; the guard and the gate run from `origin/main`'s
copy of `scripts/`, never the checkout's; and once per commit of main the next run asks the live
site two questions from outside and reverts the merge at the tip when it answers wrong.

Technical. Branch `t0-16` off `origin/main` at `0870c08`. Claimed by the scheduled run on
2026-09-14 in its own worktree; the Spec cited guidelines v1.7, which exists only on the unmerged
`t0-12` and `t0-13` branches — the repo held v1.6, and this ticket takes it to v1.8.

## Defaults taken under §4

Each is cheap to undo — a script, a document the run owns, a developer surface — and each is in
the one `default` comment on the board row.

1. **Once per commit, not "since the last Release row."** The ticket's item 5 conditions the
   deploy check on main having advanced since the last Release row, but item 2 has the run that
   merges write that row seconds after the merge, so nothing would ever count as advanced.
   `health.mjs` records the commit it last asked about in `aenima-deploy-checked` beside the run
   marker and asks once per commit, whatever the answer.
2. **`git archive` of `scripts/`, not `git show` of one file.** The ticket names
   `git show origin/main:scripts/hooks/<name>.mjs`; the guard imports `../run/permission.mjs`,
   which imports five more, so a single file piped to node would import the checkout's copies of
   the rest. The whole `scripts/` tree from `origin/main` is extracted and the hook run from there.
3. **The pull request's head bound to the checkout's HEAD** on the verdict door, and the local
   branch dropped before `gh pr merge --delete-branch` from a detached HEAD (review pass 1, Must 2;
   gh's `deleteLocalBranch` asks for the current branch only while a local copy exists, read in
   gh's `pkg/cmd/pr/merge/merge.go` against gh 2.x, not run live).
4. **Guidelines §2's Status cell** — the one-cell fix the Backlog row *Guidelines §2 Status type
   is select* asks for, which that row itself says this ticket's v1.8 pass could absorb — and the
   Releases note under it; the build-guide's hooks paragraph, which items 2–4 made stale, to v2.6.
