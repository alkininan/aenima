# T0.28 — Number task IDs across the phase

`next-id.mjs` counted within the epic. Two epics in one phase counted past each other, so an
ID that already named a task was answered to a second one: E0.4 Design conformance was answered
T0.1, the scaffold ticket's, and E0.1 Foundation is answered T0.7, E0.2's Setup. An ID names a
branch and a file under `docs/` on main, so the second task overwrites the first's record rather
than colliding anywhere a person would see it. R-0062 stopped at claim on the first of these.

The Epic now gives the phase and nothing else. The number is the lowest in that phase nobody
holds, and holding it is a task on the board whatever its epic and whatever its status, or a
branch or a file under `docs/` that still carries it — so a number outlives the task it was given
to, and no epic owns a block.
