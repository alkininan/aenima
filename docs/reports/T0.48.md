## Open questions

1. **Script-off and streamed boundaries.** A route with a `loading.tsx` streams its content into a Suspense boundary whose reveal is an inline script; with JavaScript off entirely the skeleton is what a visitor sees, on `/i/<key>` now as on `/app` before. The gap move's guarantee — a native multipart POST with React absent — holds, and the test stages that case by blocking the bundles. Whether a fully script-off render mode (the `onAllReady` shape Next gives crawlers) is wanted is a product decision. Owner: product-spec.
2. **A chrome read that fails has no surface.** `usePromise` throws a rejected read into the render, where the route's error boundary has it; §10's component error line ("Couldn't load — retry") is C-47's and does not exist yet. Owner: C-47's ticket.
3. **`e2e/item.spec.ts` "rings and glows the disclosure on keyboard focus" is a load flake.** It passes four of four alone and fails about one in three beside other workers, as T0.37's report recorded before this frame existed; its `:focus-visible` read comes back false on an element the same run shows focused. Not this ticket's assertion. Owner: T2.4's test.
4. **The readiness summary lost its clock.** §4 puts the freshness in the page topbar and the ticket says so; the summary now reads "67% · 66 of 99 points". If §8.23 means the summary to carry the clock as well, that is a spec question. Owner: design-spec.
5. **The proxy does not run locally.** An anonymous request to `/i/soc-1`, `/o/soc-2` or `/app` answers 200 from both `next dev` and the production build, and `/p/x` answers 404 — never the proxy's 307 — with `proxy.ts` and `src/lib/supabase/proxy.ts` byte-for-byte `origin/main`'s. Next's convention (its `proxy.md`: "in the project root, or inside `src` if applicable, so that it is located at the same level as `pages` or `app`") puts the file beside `src/app`, and this project's sits at the root. The 307 `production.spec.ts` and the deploy check read from `/app` has been the `/app` layout's own awaited redirect, which this ticket keeps; `updateSession`'s cookie refresh is not happening. The file is the auth boundary and not this ticket's to move — filed under Out of scope. Owner: a Fix ticket.
6. **The `chat-bubble` toggles, `aria-pressed` and the dock's column state** are *Build the dock surface*'s (T3.2, Backlog); the topbar's trailing edge and the top bar's right group leave room for them.

- **The proxy is not running.** `proxy.ts` sits at the repository root while the app lives under `src/app`; Next's `proxy.md` reads "in the project root, or inside `src` if applicable, so that it is located at the same level as `pages` or `app`".
