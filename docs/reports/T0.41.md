# T0.41 — Design-spec §6: the morph's trigger hides by opacity

**Branch:** `t0-41` · **Spec:** design-spec v2.22 → v2.23 · no drift at claim
(`version-drift.mjs`: cited 2.22, repo 2.22)

T0.37's Decision was answered *default*: the morph's trigger hides by `opacity: 0` and
`pointer-events: none`, because in Chromium an anchor hidden by `visibility` stops its
anchor-positioned panel taking pointer events under the default `position-visibility`, which §6
forbids setting. The code has said so since T0.37; the spec now does too. Three replacements and one
added changelog line, in one file.
