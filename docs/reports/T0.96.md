   §5 says it must be unset for the schedule. Today it is what lets a scheduled run use T0.10's
   scripts before T0.10 is on main, so this branch is T0.10's three commits plus this ticket's
   and the pull request carries T0.10's files until T0.10 merges, at which point it is the
   one-commit change it is. The board also has T0.10's row at Backlog while its commits are on
   this worktree's HEAD. Owner: the human merging — merge T0.10, then unset the override.

   board.json's are; a file with an integer-like key would list it first. Reading the raw text
   for true file order would be more code than the file warrants. Owner: T-next, only if
   board.json ever gains such a key.
3. The default taken — one key per line, file order, `scripts/board-ids.mjs` beside the run
   scripts — is recorded on the board thread. If the shape or the home should differ, it is one
   file and one `package.json` line.
