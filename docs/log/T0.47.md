parked the name on Vercel itself would still be read. A header of the app's own would close that,
and it is not this ticket. One thing the build met on the way: T0.44's test pinned the guidelines
header's *first line* to v1.31's note, so the v1.32 bump reddened it by construction; it now reads
the note anywhere inside the header — the rule T0.44 wrote, not the number that happened to
satisfy it.
