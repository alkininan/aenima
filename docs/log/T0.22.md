improvising: nothing in §5 said a run could pick the model that reviews its own code. The rule

refusal from Claude Code's own error text: a 429, a 5xx, an overloaded model or a lost connection
moves one step along it, and anything else, a chain with no step left, or models tried out of
order is a stop. A review that did not run is not a pass, so the ticket waits at Decision with
one comment rather than closing unreviewed. The report's reviewer section is now a table with a
model column, and `report-check.mjs` refuses a pass on a model outside the chain.
