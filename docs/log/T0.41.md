# T0.41 — Design-spec §6: the morph's trigger hides by opacity
_2026-09-24T15:18:57Z_

Design-spec v2.23 says what T0.37 shipped: the morph's trigger hides for the panel's lifetime by
`opacity: 0` and `pointer-events: none`, never by `visibility`, because in Chromium an anchor
hidden that way stops its anchor-positioned panel taking pointer events under the default
`position-visibility`, which §6 never sets. The focus sentence keeps its placement — inside the
update callback, straight after `showPopover()` — and now gives the code's reason for it: an
opacity-hidden trigger keeps focus, so a keystroke in the gap would land on a trigger nobody can
see. The focus-fixup rule no longer applies and is gone from the paragraph.

The spec is the record, so a Decision answered in code is not finished until the paragraph it
contradicted agrees. C-01 to C-04 were checked by a throwaway script again; making them a test is
its own Ready task.
