# T0.17 — Linear ordering
_2026-09-15T12:03:00Z_

T0.17 — the board is ordered the way Linear orders a backlog. Priority is Urgent · High · Medium ·
Low · None, an empty one read as Medium. Sequencing is the Blockers relation. A task is claimable
once every blocker is Done, and a Ready blocker is claimed at the highest priority of anything
not Done it holds up, however far down the chain. Ties go to the Epic's name, then the ID as
numbers, then age. `pick-next.mjs` now reads the board itself over the API and prints the
comments the run owes the tasks it passes by: one on a Ready task waiting on a Backlog blocker,
one on a member of a loop, and one when three or more Ready tasks are Urgent. It first reads
those threads, so a second run says nothing twice. `ready` is the third word. A human reply
beginning with it sets a Backlog task Ready, and the guard now stands at the Notion connector's
writes as well as at Bash, Edit and Write. It reads the thread before a Backlog task moves, lets
it move only to Ready and only on the word, refuses a task created anywhere but Backlog, and
refuses a comment without the prefix, because the connector posts as the human. The first review
found the two-step route: Backlog → Decision, then Decision → Ready, with no word. That is now the
one move out of Backlog.

The live check ran on three fixture tasks, trashed afterwards. B at Low was picked first as High
over A at High. The waiting notice was posted once and not again. The guard read C's thread and
refused a Ready write with no word, then let it through on a reply. That reply, posted with the
integration token so it would not be the model writing as the human, came back authored by the
human's own user id. So the token can still speak and write as the human past the guard, as it
could for `merge` and `apply` since T0.11. That route is filed at Backlog. The same run landed
T0.14, and T2.8 after settling its generated build-log list with main. It left T0.12 at Review
with its conflict named. Guidelines v1.9. Three review passes, run on Opus while the reviewer's
