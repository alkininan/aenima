# T0.18 — Guard the token
_2026-09-22T10:19:00Z_

T0.18 — guard the token. **The board's token speaks as the human.** `GET /v1/users/me` answers a
bot whose owner is the human's own user, so a comment it posts comes back with the human's user id
and display name, the same as the connector's. T0.17's fixture reply showed it. No field on a
comment tells a token post from a real reply, so the route cannot be detected on the thread. It
is refused where it starts. Rule (i) is the guard's first rule about a destination rather than a
program. A command that writes to the Notion API is refused: curl or wget aimed at it with a
method that is not a read, or code handed to node or python that names the API or the token and a
write. The code is read inline, from stdin through a heredoc, a `<` or a pipe, or from the file
the command runs, resolved past a `cd`. Rule (i) also reads a file run by its own path and a shell
script. Reads go through, a query or a search POST included. The pipeline's own four scripts that
name both halves pass because they are main's, byte for byte: the guard compares against the
`scripts/` it was extracted from.

The connector's other three writes that reach the board are refused on their shape at rule (h):
a page duplicated keeps its source's Status, a page moved under a database arrives with its
Status, and a data source's schema holds the options every task stands on. They are guarded by a
hook group of their own, so main's group stands as it was. Review found two Musts in pass 1: no
red-first report yet, and four ordinary shapes rule (i) let through (a path, a `cd`, stdin, case).
Both were fixed with a test apiece red first. Pass 2 was PASS, with four Shoulds recorded. The
bundled `bash -lc` shape predates this ticket and hides commands from every rule; it is filed at
Backlog, and so are the routes rule (i) does not read, among them a script's imports. The diff
touches the detector, so it waits at Review for the human's `merge`. The wall the guard stands in
front of is the integration's own capabilities, and those are the human's to narrow.
