   - `node - < post.mjs` and `cat post.mjs | node` — code on stdin from a file. `codeRun`

   - `curl -X PATCH https://API.NOTION.COM/…` and a script with `method: "post"` — `NOTION_API`
     is matched with `includes` and `NAMES_WRITE` (guard.mjs:718) is case-sensitive; curl and
     node's fetch both accept either case.

   these four are the ones a run would type without trying. Smallest correction: in
   `writesTheBoardApi`, when `name` contains a `/` and `readScript(name)` returns text, judge it
   as a shell script; in `codeRun`, when the script is `-` or absent, add the target of a `<`
   redirect to what is read; in `decide`, remember the last `cd <dir>` seen in `parse(command)`
   and resolve later scripts against it; lower-case the host and use `/i` on `NAMES_WRITE`. One
   test each, red first.
