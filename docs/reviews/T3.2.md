   can hold, whole and unmarked* and *cuts to what the column holds, and says it cut*

   second mutation and its count, or say in the row that those two were not reddened. Their claims
   are asserted elsewhere by tests that were reddened (the three AA3 loop cases), which is why

2. **`refinement_round_shape` no longer holds §6's cap as tightly as the code does.**
   `src/db/schema/tables.ts:1089`: `or (${t.outcome} = 'surfaced' and ${t.roundNo} between 1 and 3
   and ...)`. The early surfacing AA3 asks for is the one whose quote would not fit, and the
   constraint does not say so — so the table now accepts a round-1 surfacing on any objection at
   all, which is a loop skipping the cap and the database not noticing. `docs/schema.md:389-393`
   still calls the shape "the cap in the database". The smallest correction is one clause, in
   `0017` itself while it is still unapplied (after `apply` it costs an 0018): `or (outcome =
   'surfaced' and revised_version_id is null and outside_sections is null and (round_no = 3 or
   (round_no between 1 and 2 and evidence_truncated and author_position is null)))`.

3. **`fit`'s docstring says something the code does not do.** `src/lib/authoring/loop.ts:106`:
   "Cut by characters, because the column's limit is characters." `text.length` and `slice` count
   UTF-16 code units; Postgres `length()` counts characters. The direction is safe — a cut by code
   units never overflows a character limit — but it is conservative rather than exact: a quote of
   2001 astral characters is 4002 code units, fits the column at 2001, and is cut and flagged
   truncated anyway, which also routes it away from the author. Say "code units, which is the
   conservative side of the column's character limit", or cut on `[...text]`.

4. **`readHumanBaseline` returns a `versionId` nobody reads.** `src/db/queries/refinement.ts:117`
   returns `{ versionId, content }`; `src/lib/authoring/run.ts:121-124` uses `content` alone, and
   there is no other caller. AGENTS.md asks for the smallest implementation that meets the
   requirement — drop the field, or name the reader it is waiting for.
