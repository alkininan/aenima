## Findings

1. **Must — `isCommandFlag` reads bash's single-dash long options as a `-c` cluster, and `parse()`
   stops at the first word that matches, so a `-norc` in front of a real `-c` hides its string
   from every rule.** `scripts/hooks/guard.mjs:420` is

   ```js
   const isCommandFlag = (token) => /^-[A-Za-z]*c[A-Za-z]*$/.test(token);
   ```

   `-norc`, `-rcfile` and `-restricted` all match it, and bash accepts all three in that
   one-dash spelling — I ran `bash -norc -c 'echo ran-norc'`, `bash -rcfile /tmp/rc -c …` and
   `bash -restricted -c …`, and each executed. At `scripts/hooks/guard.mjs:472`,
   `args.findIndex(isCommandFlag)` then takes `-norc` as the flag and reads only the word after
   it, so the real `-c` string is never parsed: at this commit
   `parse("bash -norc -c 'pnpm db:push'")` answers `["bash -norc -c pnpm db:push", "-c"]`.
   Measured against `origin/main`'s guard with identical inputs, **refused on main and allowed at
   this commit**:

   | command | rule |
   |---|---|
   | `bash -norc -c 'pnpm db:push'` | (a) |
   | `bash -norc -c 'git push --force'` | (d) |
   | `bash -norc -c "curl -X POST https://api.notion.com/v1/comments -d @c.json"` | (i) |
   | `bash -rcfile /tmp/rc -c 'pnpm db:push'` · `bash -restricted -c 'pnpm db:push'` | (a) |
   | `bash -norc post.sh`, the script writing the board | (i) |

   The last one is the second call site: `scripts/hooks/guard.mjs:870`,
   `options.some(isCommandFlag)`, takes `-norc` for a cluster and returns `[]` before `readScript`
   is ever called, so the file is not read at all. And the ticket's own shape loses to the same
   word — `bash -norc -lc 'pnpm db:push'` is allowed here. This is a restraint the diff weakens,
   `loosening.mjs` answers `ok: true` because its corpus holds no bundled shape, and nothing on

   *Smallest correction*, both parts — I applied them to a scratch copy and re-ran the
   measurement: every row above returns to refused, every tightening the ticket asks for stays,
   and `bash --color`, `bash --version`, `pnpm test` stay allowed.

   ```js

   const ONE_DASH_LONG = new Set(["-norc", "-rcfile", "-restricted", "-noprofile", "-login",
     "-posix", "-verbose", "-version", "-help", "-debugger"]);

     !ONE_DASH_LONG.has(token) && /^-[A-Za-z]*c[A-Za-z]*$/.test(token);
   ```
