## Findings

**1. Must — `ownSections` drops everything after `## Cited`, so an addendum round's names are
never checked.**

`scripts/run/claims.mjs:53-57`:

    export function ownSections(text) {
      const body = String(text ?? "");
      const cited = CITED_HEADING.exec(body);
      return cited ? body.slice(0, cited.index) : body;
    }

The comment above it justifies leaving the quoted spec text alone, and that reasoning is right.
What the code does is wider than the reasoning: it keeps the head of the file and discards the
tail, and an `## Addendum` section written below `## Cited` goes with it. Measured over the seven
ticket files in `docs/tickets/` that carry an addendum, two place it after the Cited section —
`docs/tickets/T0.12.md:415` (Cited at `:65`) and `docs/tickets/T0.19.md:253` (Cited at `:44`) —
and for those two `ownSections` returns 65 lines of 471 and 44 of 659, addendum included in what
is thrown away. T0.12's addendum alone claims `.claude/skills/ticket/SKILL.md`,
`scripts/run/README.md`, `docs/guidelines.md` and `docs/build-log.md`; none of them would be
looked up.

This is the half of AC1 that says *every* backticked path and identifier in a ticket file, and it
fails silently: the output is a shorter list, with nothing saying a section was skipped. It fails
on the case this diff names in the same breath — `docs/guidelines.md:483-490` puts "then check the
names the ticket claims against origin/main (claims.mjs)" and "an addendum round adds the reply as
its own section" in one step, and an addendum is the round whose names are freshest, written by a
human at Review and never seen by the code.

Smallest correction: drop the Cited *section* rather than the tail — end it at the next `## `
heading that is not inside a fence, which `codeSpans` already tracks the state for — and add one
TC1 case: a fixture whose `## Addendum` follows `## Cited` and names an absent path, asserted into
`absent`. I am confident about the behaviour; it is measured. Where I am less sure is the smallest
fix: if the intent is that an addendum always sits above `## Cited`, one line in the skill's step 2
saying so, held by TC5, would also settle it — but the two files already on main show the
placement is not reliable today, so the code is the side that closes it for them too.
