## Findings

1. **Must — the guard's Backlog → Ready check is skipped by a two-step status write.**
   `scripts/hooks/guard.mjs:838` — `if (!granted.ok && (status === null || status === "Backlog"))`.
   A Status write to anything other than Ready is never judged (the (h) block only looks at
   `setsReady`, then `if (tool !== "Bash") return null`). So a run can set a Backlog task to
   `Decision` — allowed, no board read — and then to `Ready` — allowed, because the guard now reads
   the page at Decision. No `ready` was ever said. The same goes for `create-pages`
   (`guard.mjs:845`): only `Status: "Ready"` is refused, so a task created at `Decision` and then
   set Ready skips the go too. That breaks AC3 ("the word from the model alone does nothing") and
   the hard boundary the diff adds at `docs/guidelines.md:499` ("no Backlog task set Ready until it
   has read your `ready`"), and no test tries the two-step path.
   Smallest fix: §3 allows exactly one move out of Backlog, to Ready. So on any `update-page` that
   writes `Status`, read the page. If it is at Backlog, refuse every target except Ready, and allow
   Ready only on the word. In `create-pages`, refuse any `Status` other than `Backlog` (or empty).
   Add one test for each two-step path.

2. **Must — no record that any new test was seen failing first.** `docs/reports/T0.17.md` is not
   in the tree, and the record is not in the commit or the ticket either. §5 step 4 asks for "new
   logic has tests observed failing first, the mutation and the count recorded per test", and the
   ticket's Done line says "TC1–TC6 observed". Nothing says which change turned TC1–TC6 red, what
   count went green, or that TC1 and TC3 were "observed live on fixtures, deleted after". The run's
   transcript does show the fixture rows being created, but that is not a record. Until that table
   exists, every new test in this diff is unverified.
   Smallest fix: write the red-first table for TC1–TC6 (per test: the change that made it red, the
   count that went green), plus a line on what the live fixture check saw and that the fixtures
   were trashed.
